# 硬體與接線指南

## 最小接線

Logger 採 RX-only 設計，只需要接收目標設備的 TX：

```text
目標板 UART TX ── 1 kΩ ── ESP32-C3 GPIO4
目標板 GND  ───────────── ESP32-C3 GND
```

不要連接 C3 的 UART TX，也不要把兩塊板子的 3.3 V 或 5 V 電源腳互接。兩塊板子各自供電，但必須共地。

## 電壓確認

ESP32-C3 GPIO 不耐 5 V。接線前應使用電表或示波器確認：

- Idle 狀態約 3.3 V。
- 訊號低準位接近 0 V。
- 沒有負電壓或高於 3.6 V 的尖峰。

遇到下列介面必須加轉換器：

| 介面 | 需要的前端 |
|---|---|
| 5 V TTL UART | 電平轉換器或適當分壓 |
| RS-232 | MAX3232 類收發器 |
| RS-485 | MAX3485 類 3.3 V 收發器 |
| 長線／不同電源系統 | 數位隔離器或隔離式收發器 |

## GPIO 選擇

預設 GPIO4 只是一個安全的常見選擇。不同 C3 開發板可能將 GPIO4 接到 LED、感測器或其他周邊。修改前請查閱板子原理圖。

避免使用：

- Flash 或 PSRAM 相關腳位。
- USB D+／D- 腳位。
- 會影響 Boot mode 的 Strapping pins，除非已確認外部電路不會拉錯電位。

GPIO 可從 Web 設定，不必重新編譯。若輸入錯誤導致無法收包，仍可從 Web 改回。

## 外殼與產品化建議

- UART 接頭明確標示 `GND`、`RX`、`3.3V ONLY`。
- 訊號線串聯 470 Ω～2.2 kΩ；本專案建議 1 kΩ。
- 工業環境加入 ESD、防反接與隔離。
- Logger 使用獨立、穩定的 USB 電源。
- 不要讓天線緊貼金屬外殼、電源模組或繼電器。
